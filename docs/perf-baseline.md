# Performance baseline (2026-10-26)

Release build, GCC C++23, 2 vCPU Intel Xeon Platinum 8255C at 2.50 GHz,
1.9 GiB RAM and 6 GiB swap, Linux 6.8.0. Each sample is converted five times
by `tests/perf/run_perf.py`; wall time is the median and RSS is the largest
peak reported by `/usr/bin/time`.

The 1/5/20 MiB DOCs are generated by LibreOffice from repeatable FODT with
chapters, tables, footnotes, headers and footers. LibreOffice's 50 MiB pure
text DOC export contains a CHPX FKP with `crun=0`, which
[[MS-DOC] §2.9.33](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/f5f10f04-d4cc-4ebd-86df-0de6d227675c)
forbids. The 50 MiB fixture repacks the valid 20 MiB structured DOC with a
30 MiB deterministic, unreferenced binary `Data` stream. It measures the
50 MiB CFB and I/O envelope,
while the formatted text path remains that of the 20 MiB sample. The generator
records this composition in its output.

| Input | Actual MiB | Median wall s | Peak RSS MiB |
|---|---:|---:|---:|
| 1 MiB | 1.00 | 0.487 | 77.9 |
| 5 MiB | 5.00 | 2.841 | 377.6 |
| 20 MiB | 20.00 | 13.929 | 1355.0 |
| 50 MiB | 50.24 | 14.840 | 1415.4 |

`DOCCRAFT_PROFILE=1` prints stage timings to stderr. One warmed 50 MiB run:

| Stage | Milliseconds |
|---|---:|
| Format parsing and text extraction | 14692.661 |
| Input read | 334.156 |
| CFB stream extraction | 83.857 |
| XML generation | 73.679 |
| ZIP compression | 67.072 |
| CFB header/FAT parse | 1.022 |

The format stage accounts for roughly 96.2% of this 15.28 s single run. The
50 MiB <5 s target is missed by about 3.0× at the five-run median. The current
`ReadChars` path materializes one `Char` (with a `std::string`) per character;
profiling that representation and the formatting lookup is the next measured
optimization task. `perf record` was unavailable because
`perf_event_paranoid=4`, so these are coarse wall stage measurements.
Four synthetic sizes do not establish a population p99; that target needs a
representative document distribution in a later benchmark.

Reproduce with:

```bash
python3 tests/perf/gen_corpus.py
python3 tests/perf/run_perf.py
DOCCRAFT_PROFILE=1 build/src/cli/doccraft convert build/perf/structured-50mb.doc -o /tmp/perf-out.docx
```
